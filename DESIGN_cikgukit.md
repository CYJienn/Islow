# CikguKit Design (applies to worksheets AND the pitch deck)

- Palette: Rainforest #1F4D3A (primary), Paper #FAF6EE (background), Hornbill #E8872A (accent, one use per page), Ink #1B1B1B (text), Rule #D9D2C3 (lines).
- Fonts: Atkinson Hyperlegible (worksheets and body, built for readability), Fraunces (deck headings).
- Vibe: warm, practical, trustworthy.
- Radius 8px; spacing scale 4 / 8 / 16 / 24 / 40.
- Components: flat cards, 1px rules, no shadows, large print-friendly text (12pt+ on worksheets).
- Worksheets are black-and-white safe: the school prints them. Never rely on color to carry meaning.
- Never: default blue buttons, stock-photo teachers, emoji in worksheets, decorative clip-art.
- Deck: one point per slide, big number first, the demo before the architecture.
- Everything is made inside WorkBuddy (Office suite or an HTML-slide skill), so these are instructions to give it, not files to import.
